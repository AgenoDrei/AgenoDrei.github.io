# AgenoDrei.github.io

Simon Mueller's personal academic homepage, hosted on GitHub Pages at [AgenoDrei.github.io](https://AgenoDrei.github.io). Built with [Jekyll](https://jekyllrb.com/) on the [al-folio](https://github.com/alshedivat/al-folio) theme.

Content lives in [_pages/about.md](_pages/about.md), [_data/cv.yml](_data/cv.yml) / [assets/json/resume.json](assets/json/resume.json), and [_bibliography/papers.bib](_bibliography/papers.bib).

See [CLAUDE.md](CLAUDE.md) for local development, build, and formatting commands. Pushing to `master` auto-deploys via GitHub Actions.
